The Authenticator method is enabled by default on every tenant. To toggle please navigate to <Breadcrumb>Tenants -> Edit Tenant -> Multi-Factor</Breadcrumb>. The authenticator method is also referred to as Google Authenticator or Time-Based One-Time Password (TOTP).

## Enable MFA method on Tenant (Admin Facing)

The authenticator factor is enabled by default at the tenant level.  It can be toggled on and off as needed.

![Toggle Authenticator On Tenant](/img/docs/lifecycle/manage-users/account-management/toggle-authenticator-tenant.png) {/* TODO DELETE SCREENSHOT */}

## Enable Authenticator Factor from Account Management (User Facing)

![Account Management Index](/img/docs/lifecycle/manage-users/account-management/account-management-index-crop.png) {/* TODO DELETE SCREENSHOT */}

<Screenshot url="/account/?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e&prompt=login" id="lifecycle_manageUsers_accountManagement_overview_4" alt="The self-service account management home page" />

1. Navigate back to your account page.
1. Click <Breadcrumb>Manage two-factor</Breadcrumb>
1. Click <Breadcrumb>Add two-factor</Breadcrumb>
1. There will be an option for an `Authenticator app`.

![Add Factors](/img/docs/lifecycle/manage-users/account-management/add-factors-home-crop.png) {/* TODO DELETE SCREENSHOT */}

<Screenshot url="/account/two-factor/?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e&prompt=login" id="lifecycle_manageUsers_accountManagement_overview_5" alt="The two-factor authentication management page with no configured methods" />

![Authenticator Add Account](/img/docs/lifecycle/manage-users/account-management/authenticator-add-account.png) {/* TODO DELETE SCREENSHOT */}

<Screenshot url="/account/two-factor/enable/?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e&prompt=login" id="lifecycle_manageUsers_accountManagement_twoFactorAuthenticator_2" alt="The authenticator app enrollment form showing the QR code and verification code field" />

Next,

1. Scan the QR code with your favorite authenticator application such as Google Authenticator or Authy.
1. (Optional) Enter a name for this method (for example, `Google Authenticator`).
1. Enter the provided code.
1. Click the <Breadcrumb>Enable</Breadcrumb> button.

## Recovery Codes (User Facing)

Now you will be presented with recovery codes. Save these in a safe space.

![Recovery Codes](/img/docs/lifecycle/manage-users/account-management/mfa-recovery-codes-crop.png) {/* TODO DELETE SCREENSHOT */}

<Screenshot url="/account/two-factor/enable/?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e&prompt=login" id="lifecycle_manageUsers_accountManagement_overview_6" alt="The recovery codes generated when a user enables two-factor authentication" />

<Icon name="trophy" /> Success!

Upon the next login, you will be prompted for a code displayed by the Authenticator App in addition to your password.

With the Authenticator method enabled, if you log out and log back in you will be presented with the following screen in addition to the typical login screen.
