Phone two-factor is not enabled by default. Configure your tenant by navigating to <Breadcrumb>Tenants -> Edit Tenant -> Multi-Factor</Breadcrumb>.

## Enable MFA method on Tenant (Admin Facing)

![Configure Tenant SMS](/img/docs/lifecycle/manage-users/account-management/enable-sms-tenant.png) {/* TODO DELETE SCREENSHOT */}

You can enable the phone factor on the tenant level by following these steps:

- Set SMS and/or Voice to enabled
- For each enabled message type, select a `messenger` (previously created, see [documentation](/docs/email/))
- For each enabled message type, select a `template` (FusionAuth ships with a default to be customized if needed)

### Enable Phone Factor from Account Management (User Facing)

![Account Management Index](/img/docs/lifecycle/manage-users/account-management/account-management-index-crop.png) {/* TODO DELETE SCREENSHOT */}

<Screenshot url="/account/?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e&prompt=login" id="lifecycle_manageUsers_accountManagement_overview_4" alt="The self-service account management home page" />

1. Navigate back to your account page.
2. Click <Breadcrumb>Manage two-factor</Breadcrumb>
3. Click <Breadcrumb>Add two-factor</Breadcrumb>
4. There will be an option for Phone.

![Add Factors](/img/docs/lifecycle/manage-users/account-management/add-factors-home-crop.png) {/* TODO DELETE SCREENSHOT */}

<Screenshot url="/account/two-factor/?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e&prompt=login" id="lifecycle_manageUsers_accountManagement_overview_5" alt="The two-factor authentication management page with no configured methods" />
![Add SMS Authenticator](/img/docs/lifecycle/manage-users/account-management/sms-configure-cropped.png) {/* TODO DELETE SCREENSHOT */}

<Screenshot url="/account/two-factor/enable/?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e&prompt=login" id="lifecycle_manageUsers_accountManagement_twoFactorPhone_2" alt="The phone two-factor enrollment form with a mobile phone number entered" />

Next,

1. Enter your phone number.
1. If SMS and Voice are both enabled, select which type of message to send.
1. Click on `Send a one-time-code`.
1. (Optional) Enter a name for this method (for example, `Work phone`).
1. Enter the provided code.
1. Click <Breadcrumb>Enable</Breadcrumb>.

## Recovery Codes (User Facing)

Now you will be presented with recovery codes. Save these in a safe space.

![Recovery Codes](/img/docs/lifecycle/manage-users/account-management/mfa-recovery-codes-crop.png) {/* TODO DELETE SCREENSHOT */}

<Screenshot url="/account/two-factor/enable/?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e&prompt=login" id="lifecycle_manageUsers_accountManagement_overview_6" alt="The recovery codes generated when a user enables two-factor authentication" />

<Icon name="trophy" /> Success!

Upon the next login, you will be prompted for a code sent by phone in addition to your password. If the tenant has both SMS and Voice message types enabled you will be asked to choose which type to receive, otherwise the message will be sent automatically.
