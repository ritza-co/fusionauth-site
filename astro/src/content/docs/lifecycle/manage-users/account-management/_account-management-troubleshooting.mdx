
Not able to get your account management page up and running?  Below are common issues and how to fix them.

### Not Registered

Please note, if you are not registered for an application, you will not be able to manage your account information from these self service account management.

From the admin UI click on <Breadcrumb>Users -> Manage -> Registrations Tab -> Add registration -> Add User</Breadcrumb>.  Another option is to be programmatically added to the application through an API call.

### Registered But Configuration Needed

If you see this, you have to select a form to use.

![Login Screen](/img/docs/lifecycle/manage-users/account-management/configuration-incomplete-account.png) {/* TODO DELETE SCREENSHOT */}

<Screenshot url="/account/?client_id=e9fdb985-9173-4e01-9d73-ac2d60d1dc8e&prompt=login" id="lifecycle_manageUsers_accountManagement_troubleshooting_2" alt="The account home showing the warning displayed when no self-service form is configured" />

To set a self service form, click under <Breadcrumb>Applications -> Edit Application -> Registration</Breadcrumb>
